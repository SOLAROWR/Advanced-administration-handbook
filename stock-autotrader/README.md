# 📈 나만의 국내주식 자동매매 프로그램

한국투자증권 **KIS Open API**로 국내주식을 자동으로 사고파는 파이썬 프로그램입니다.
코딩 초보자도 따라 할 수 있게 **안전장치를 먼저** 넣어서 만들었습니다.

> ⚠️ **투자 책임은 본인에게 있습니다.** 이 프로그램은 수익을 보장하지 않습니다.
> 반드시 **모의투자 → 소액 실전** 순서로 진행하세요.

---

## 1. 전체 기획

### 왜 한국투자증권 API인가?
| 비교 | 한국투자증권 (KIS) ✅ | 키움증권 |
|---|---|---|
| 방식 | 인터넷 주소로 요청 (REST) | 윈도우 전용 프로그램 연동 (OCX) |
| 컴퓨터 | 윈도우·맥·클라우드 모두 가능 | 윈도우 + 32비트 파이썬만 가능 |
| 모의투자 | 무료 지원 | 지원 |
| 난이도 | 쉬움 | 어려움 |

### 매매 전략 (기본값)
라씨매매비서처럼 **장 마감 직전(15:15)에 하루 한 번** 신호를 계산합니다.

- 🔴 **매수**: 5일 이동평균선이 20일 이동평균선을 위로 뚫음(**골든크로스**)
  - 그리고 RSI가 70 미만(과열 아님)
  - 그리고 거래량이 20일 평균보다 많음
- 🔵 **매도**: 5일선이 20일선을 아래로 뚫음(**데드크로스**)
- 🛡️ **손절**: 산 가격보다 **-5%** 떨어지면 장중 언제든 자동 매도
- 💰 **익절**: 산 가격보다 **+10%** 오르면 장중 언제든 자동 매도

### 안전장치 (가장 중요)
1. 기본값이 **모의투자 + 기록만(dry_run)** 입니다. 실제 돈은 절대 안 움직입니다.
2. 실전 모드는 `.env`에 `I_UNDERSTAND_REAL_MONEY=YES`를 직접 적어야만 켜집니다.
3. **감시종목(watchlist)에 없는 주식은 절대 건드리지 않습니다.** 직접 산 주식은 안전합니다.
4. 최대 보유 종목 수, 한 종목 최대 비중, 1회 주문 최대 금액, 하루 최대 매수 횟수 제한이 있습니다.
5. 같은 날 판 종목은 다시 사지 않습니다.
6. 모든 주문은 `logs/trades.csv`에 기록됩니다. 엑셀로 열어볼 수 있습니다.

### 진행 로드맵
| 단계 | 할 일 | 기간 |
|---|---|---|
| **1단계** ✅ | 프로그램 뼈대 + 전략 + 안전장치 + 백테스트 (지금 완료) | — |
| **2단계** | 한국투자증권 계좌·API 신청, 내 PC에 설치, `--status`로 연결 확인 | 1~3일 |
| **3단계** | 백테스트로 감시종목별 성적 확인, 설정값 조정 | 1주 |
| **4단계** | 모의투자 `dry_run: true`(기록만)로 매일 실행 | 1주 |
| **5단계** | 모의투자 `dry_run: false`(모의계좌에 실제 주문) | 2~4주 |
| **6단계** | 실전 소액(예: 50~100만 원)으로 시작 | 1개월+ |
| **7단계(선택)** | 텔레그램 알림, 클라우드 서버에서 24시간 실행, 전략 추가 | — |

## 2. 폴더 구성

```
stock-autotrader/
├── run_bot.py            ← 자동매매 실행
├── run_backtest.py       ← 과거 데이터로 전략 시험
├── config.example.yaml   ← 설정 예시 (복사해서 config.yaml 로)
├── .env.example          ← 비밀번호 예시 (복사해서 .env 로)
├── autotrader/
│   ├── kis_api.py        ← 한국투자증권과 통신
│   ├── strategy.py       ← 매수/매도 신호 계산
│   ├── indicators.py     ← 이동평균, RSI 계산
│   ├── risk.py           ← 손절/익절, 매수 수량
│   ├── bot.py            ← 시간 맞춰 자동으로 돌리는 본체
│   ├── backtest.py       ← 백테스트 계산
│   └── notifier.py       ← 텔레그램 알림
└── tests/                ← 프로그램이 제대로 동작하는지 자동 검사
```

## 3. 따라 하기 (처음 한 번만)

### ① 한국투자증권 준비
1. 한국투자증권 **비대면 계좌 개설** (앱 "한국투자")
2. [KIS Developers](https://apiportal.koreainvestment.com) 접속 → **API 신청**
3. **모의투자 신청** (한국투자 홈페이지 → 모의투자) → 모의투자 계좌번호 받기
4. KIS Developers에서 **모의투자용 앱키(APP KEY)와 앱시크릿(APP SECRET)** 발급
   - 실전용과 모의투자용 키가 **따로** 있습니다.

### ② 내 컴퓨터에 파이썬 설치
1. [python.org](https://www.python.org/downloads/)에서 Python 3.11 이상 설치
   - 설치 첫 화면에서 **"Add Python to PATH"를 반드시 체크**하세요.
2. 이 폴더를 내 컴퓨터로 내려받기 (GitHub → Code → Download ZIP → 압축 풀기)
3. 폴더에서 주소창에 `cmd` 입력 후 Enter → 검은 창(명령 프롬프트)이 열림
4. 아래를 입력:
   ```
   pip install -r requirements.txt
   ```

### ③ 설정 파일 만들기
1. `.env.example`을 복사해서 이름을 `.env`로 바꾸고 앱키, 시크릿, **모의투자 계좌번호**를 적습니다.
2. `config.example.yaml`을 복사해서 이름을 `config.yaml`로 바꿉니다.
   - 감시종목, 손절·익절 비율 등을 원하는 대로 바꾸세요.

### ④ 연결 확인
```
python run_bot.py --status
```
현금·보유종목이 나오면 성공입니다. 🎉

### ⑤ 백테스트 (과거 성적 보기)
```
python run_backtest.py --all --days 500
```
- **총수익률**과 **단순보유 수익률**을 비교하세요. 그냥 들고 있는 것보다 나은지가 핵심입니다.
- **MDD(최대낙폭)**는 "최악일 때 얼마나 잃었나"입니다. 이 숫자를 견딜 수 있어야 합니다.

### ⑥ 오늘 신호만 보기 (주문 없음)
```
python run_bot.py --signals
```

### ⑦ 자동매매 시작
```
python run_bot.py
```
- 평일 09:00~15:30에만 동작합니다. 그 외 시간에는 조용히 기다립니다.
- 끄려면 **Ctrl + C**를 누르세요.
- 컴퓨터가 켜져 있고 절전 모드가 아니어야 합니다.
- 윈도우라면 `start_bot.bat`을 더블클릭해도 실행됩니다.

## 4. 텔레그램 알림 받기 (선택)
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 토큰 받기
2. 만든 봇에게 아무 메시지나 보내기
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 접속 → `"chat":{"id":숫자` 확인
4. `.env`의 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`에 입력

매수·매도·손절·오류가 생기면 휴대폰으로 알림이 옵니다.

## 5. 실전으로 넘어갈 때 체크리스트
- [ ] 모의투자 dry_run=false로 **2주 이상** 오류 없이 돌았다
- [ ] `logs/trades.csv` 기록을 보고 매매 내용이 이해된다
- [ ] 백테스트 MDD만큼 잃어도 생활에 지장이 없는 금액이다
- [ ] KIS Developers에서 **실전용** 앱키를 새로 받았다 (모의투자 키와 다름)
- [ ] `.env`의 키·계좌번호를 실전용으로 바꿨다
- [ ] `config.yaml`: `mode: real`, `max_order_amount`를 작게 잡았다
- [ ] `.env`: `I_UNDERSTAND_REAL_MONEY=YES`

## 6. 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| `config.yaml 파일이 없습니다` | `config.example.yaml`을 복사해서 이름을 바꾸세요 |
| `.env 에 다음 값이 비어 있습니다` | `.env` 파일에 키와 계좌번호를 넣으세요 |
| `토큰 발급 실패` | 앱키/시크릿 오타, 또는 모의/실전 키가 바뀌었는지 확인. 토큰은 1분에 1번만 발급됩니다 |
| `초당 거래건수를 초과` | 잠시 후 자동 재시도됩니다. 감시종목 수를 줄여도 됩니다 |
| TR ID 관련 오류 | 증권사가 값을 바꿨을 수 있습니다. `autotrader/kis_api.py`의 `TR_IDS`를 최신 문서와 비교하세요 |

## 7. 개발자용
```
python -m pytest -q     # 자동 검사 실행
```
- 증권사 서버 없이도 가짜(Fake) 응답으로 전체 동작을 검사합니다.
- 전략을 바꾸고 싶으면 `autotrader/strategy.py`의 `signal_at` 함수만 고치면 됩니다.
  백테스트와 실제 봇이 같은 함수를 쓰기 때문에 결과가 일치합니다.
